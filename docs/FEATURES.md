# Features

What the simulator supports today. Update this file in the same pull request as the
feature. If behavior is simplified compared to real networks, say how.

Legend: ✅ supported · 🟡 partial · ❌ not yet

## Network behavior

| Feature             | Status | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Cables              | ✅     | Port to port. Copper joins Ethernet ports, fiber joins SFP ports; no straight/crossover distinction (auto-MDI-X). 0.25 ms per hop. No speed or duplex.                                                                                                                                                                                                                                                                                                                                                       |
| Switching loops     | ✅     | A cable that closes a loop between switches is refused unless every switch in it runs STP. STP cannot be turned off on a switch inside a loop (a simulator guard: Linux would let frames circle forever). Loops between routers are allowed; TTL ends them.                                                                                                                                                                                                                                                  |
| MAC learning        | ✅     | 300 s ageing like the Linux bridge; entries on a port are flushed when it loses carrier.                                                                                                                                                                                                                                                                                                                                                                                                                     |
| VLANs               | ✅     | Linux bridge `vlan_filtering`: per-port VLAN membership, PVID and egress untagged, 802.1Q tags on trunks; the FDB is per VLAN. VLAN interfaces (`eth0.10`) on hosts and routers for inter-VLAN routing. Off by default, like Linux. No VLAN 0/priority tags, no QinQ, no GVRP.                                                                                                                                                                                                                               |
| Spanning Tree       | 🟡     | 802.1D as the Linux bridge runs it: root election by priority and MAC, root path cost (copper 4, fiber 2), root/designated/alternate roles, 15 s listening + 15 s learning, topology changes flush learned addresses. BPDUs are sent on changes instead of every 2 s, there is no max age (failures are seen from carrier loss), one tree for all VLANs, no RSTP. A loaded lab starts already converged.                                                                                                     |
| OSPF (BIRD)         | 🟡     | OSPFv2 as real packets (IP protocol 89, 224.0.0.5): hellos every 10 s, 40 s dead interval, router LSAs flooded on change, Dijkstra, routes exported to the kernel table when `protocol kernel` has `export all`. One area; no DR/BDR election (neighbors are Full after two-way hellos); LSAs never age; no ECMP, authentication, external routes or virtual links. See ADR 0007.                                                                                                                            |
| IPv6                | 🟡     | EUI-64 link-local address on every IP interface, static addresses and routes, Neighbor Discovery (solicited-node multicast), ICMPv6 echo, time exceeded and unreachable, forwarding with hop limits, SLAAC from radvd router advertisements (hosts send a router solicitation when their link comes up; radvd says goodbye with lifetime 0 when stopped). ICMPv6 only: no TCP/UDP, DNS, DHCPv6 or traceroute over IPv6; no DAD, privacy addresses, lifetimes or periodic RAs; nftables does not filter IPv6. |
| WireGuard VPN       | 🟡     | Layer 3 tunnel interfaces carrying IPv4 inside UDP (port 51820), peers with endpoints and allowed IPs (cryptokey routing in both directions), endpoint roaming, one-round-trip handshake on first use, transfer counters. Keys are deterministic stand-ins for Curve25519 (same format; not secure); no cookies, rekeying, preshared keys, keepalive packets or IPv6 inside the tunnel; captures show the sealed payload scrambled.                                                                          |
| SSH                 | 🟡     | `sshd` on TCP 22 and an interactive `ssh` client (password prompt, remote prompt, Ctrl+C passed to the remote command, `exit`). Root's password is `netforge` until changed with `chpasswd` (stored hashed in `/etc/shadow`). Version banners are clear text; everything after shows as "Encrypted packet" (a reversible scramble, not real encryption). No host keys/known_hosts, public keys, scp or port forwarding.                                                                                      |
| Firewall (nftables) | 🟡     | Tables (`ip`, `inet`), base chains on the five IPv4 hooks with priority and policy, rules matching `iifname`/`oifname`, `ip saddr`/`daddr`/`protocol`, `meta l4proto`, `tcp`/`udp` `sport`/`dport` (sets too), `icmp type`, `ct state`; statements `counter`, `accept`, `drop`, `reject` (ICMP port unreachable), `masquerade`, `snat to`, `dnat to`. No `jump`/`goto`, maps, named sets, `log`, `limit`, IPv6. Saved with the lab as `nft list ruleset` text; rule handles are renumbered on load.          |
| NAT and conntrack   | ✅     | Linux-style connection tracking (NEW, ESTABLISHED, RELATED); NAT chains see only the first packet; masquerade/snat remap clashing source ports and ICMP ids; ICMP errors are translated with their connection. Idle timeouts: ICMP and UDP 30 s, TCP 300 s (Linux keeps established TCP for 5 days); no TCP state machine. Not saved with the lab.                                                                                                                                                           |
| ARP                 | ✅     | 3 probes, 1 s apart, then `FAILED`. Entries stay `REACHABLE` forever (no `STALE`/aging).                                                                                                                                                                                                                                                                                                                                                                                                                     |
| IPv4 routing        | ✅     | Connected and static routes, longest prefix match, default gateway. Routers look the route up, then check and decrement TTL, like Linux. No policy routing, no metrics.                                                                                                                                                                                                                                                                                                                                      |
| ICMP                | ✅     | Echo, time exceeded, destination unreachable (net, host after failed ARP, port). Errors about the sender's own packets are reported locally, like Linux. Broadcast pings are ignored.                                                                                                                                                                                                                                                                                                                        |
| TCP                 | 🟡     | Three-way handshake, data with seq/ack, FIN close, RST for closed ports, SYN retried 3 times (1, 2, 4 s). One segment per application message; no data retransmission, windowing or congestion control.                                                                                                                                                                                                                                                                                                      |
| Wi-Fi               | 🟡     | Association by SSID and WPA2 passphrase, range from canvas distance (340 units), signal from distance. No beacons, authentication frames, channels, interference or roaming handover; association happens without frames on the wire.                                                                                                                                                                                                                                                                        |
| HTTP                | ✅     | HTTP/1.1 GET/HEAD, `Connection: close`; 200, 400, 404, 501.                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Email               | 🟡     | SMTP delivery to local mailboxes (`/var/mail/USER`, mbox) and POP3 retrieval; dot-stuffing. No relaying between servers, no MX records, any POP3 password accepted.                                                                                                                                                                                                                                                                                                                                          |
| Files               | ✅     | Per-device files (64 KB per file, 512 KB in all), saved with the lab.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| UDP                 | ✅     | Sockets with ephemeral ports from 32768; closed ports answer with port unreachable.                                                                                                                                                                                                                                                                                                                                                                                                                          |
| DHCP                | ✅     | dnsmasq server and dhclient: Discover/Offer/Request/Ack, Nak, Release. The server answers on the interface whose subnet contains the range, and gives itself as gateway and DNS server unless options say otherwise. No relays; leases are not renewed or saved, and no address conflict check.                                                                                                                                                                                                              |
| DNS                 | ✅     | dnsmasq answers its host records and its DHCP clients' hostnames; A records only, no upstream servers, no caching, no `/etc/hosts`.                                                                                                                                                                                                                                                                                                                                                                          |
| Interface up/down   | ✅     | Carrier needs both ends cabled and up; `NO-CARRIER` and `linkdown` shown otherwise.                                                                                                                                                                                                                                                                                                                                                                                                                          |

## Shell (Linux-style)

| Command                                                                                                                                                                                       | Status | Notes                                                                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ip addr [show\|add\|del\|flush]`                                                                                                                                                             | ✅     | iproute2 output and error messages; prefixes like `ip a`.                                                                                                                                             |
| `ip link [show]`, `ip link set IF up\|down`                                                                                                                                                   | ✅     |                                                                                                                                                                                                       |
| `ip link add link IF name NAME type vlan id VID`, `ip link del NAME`                                                                                                                          | ✅     | VLAN interfaces only; they start down.                                                                                                                                                                |
| `ip link set br0 type bridge vlan_filtering 0\|1`                                                                                                                                             | ✅     | Switches.                                                                                                                                                                                             |
| `ip neigh [show\|flush]`                                                                                                                                                                      | ✅     |                                                                                                                                                                                                       |
| `ip route [show\|add\|del\|get]`                                                                                                                                                              | ✅     | `add DST [via GW] [dev IF]`, `DST` is `ADDR/LEN` or `default`. No `replace`, `metric`, `table`.                                                                                                       |
| `sysctl [-w] net.ipv4.ip_forward[=0\|1]`                                                                                                                                                      | ✅     | The only sysctl key.                                                                                                                                                                                  |
| `ping [-c N] [-t TTL] HOST`                                                                                                                                                                   | ✅     | Default 4 packets (Linux pings forever). Names are resolved with DNS. Ctrl+C stops.                                                                                                                   |
| `traceroute [-m MAX] HOST`                                                                                                                                                                    | ✅     | UDP probes from port 33434, 3 per hop, 5 s wait; `*`, `!N`, `!H`.                                                                                                                                     |
| `dnsmasq [OPTIONS]`, `killall dnsmasq`                                                                                                                                                        | ✅     | `--dhcp-range`, `--dhcp-option=option:router\|dns-server,IP` (or 3/6), `--address=/NAME/IP`, `--host-record=NAME,IP`. Runs in the background.                                                         |
| `dhclient [-r] IF`                                                                                                                                                                            | ✅     | Prints the `-v` messages; 4 Discover attempts, 3 s apart.                                                                                                                                             |
| `dig [@SERVER] [+short] NAME`                                                                                                                                                                 | ✅     | A records, dig-style output, NXDOMAIN, timeouts, connection refused.                                                                                                                                  |
| `resolvectl [status\|dns\|revert\|query]`                                                                                                                                                     | ✅     | One global list of DNS servers.                                                                                                                                                                       |
| `bridge fdb [show]`                                                                                                                                                                           | ✅     | Switches only.                                                                                                                                                                                        |
| `bridge vlan [show]`, `bridge vlan add\|del dev IF vid VID [pvid] [untagged]`                                                                                                                 | ✅     | Switches. No VID ranges.                                                                                                                                                                              |
| `bridge link [show]`, `ip link set br0 type bridge stp_state 0\|1 priority N`, `ip -d link show br0`                                                                                          | ✅     | Port STP states; bridge and root ids, root port and cost.                                                                                                                                             |
| `nft [-a] [-f FILE] list ruleset\|tables\|table`, `add\|create\|insert\|delete table\|chain\|rule`, `flush ruleset\|table\|chain`                                                             | ✅     | See Firewall above. Error messages are shortened.                                                                                                                                                     |
| `conntrack -L`, `conntrack -F`                                                                                                                                                                | ✅     |                                                                                                                                                                                                       |
| `bird [-c FILE]`, `birdc show protocols\|show ospf neighbors\|show route\|configure\|down`, `killall bird`                                                                                    | ✅     | Reads `router id`, `protocol kernel` export, and `protocol ospf` areas, interfaces (with `*` patterns) and costs from `/etc/bird.conf`.                                                               |
| `ip -6 addr\|route\|neigh`, `ip addr add 2001:db8::1/64 dev IF`, `ping ADDR6`, `ping fe80::1%IF`, `ping6`, `sysctl net.ipv6.conf.all.forwarding`                                              | ✅     | `ip -4` limits output to IPv4.                                                                                                                                                                        |
| `radvd [-C FILE]`, `killall radvd`                                                                                                                                                            | ✅     | Reads `interface IF { AdvSendAdvert on; prefix P/64 { }; };` from `/etc/radvd.conf`; needs IPv6 forwarding.                                                                                           |
| `wg genkey`, `wg pubkey`, `wg show [IF]`, `wg showconf IF`, `wg set IF [listen-port N] [private-key FILE] [peer KEY [remove] [endpoint IP:PORT] [allowed-ips LIST] [persistent-keepalive N]]` | ✅     | Endpoints are IP addresses (no host names).                                                                                                                                                           |
| `ip link add wg0 type wireguard`, `wg-quick up\|down IF`                                                                                                                                      | ✅     | wg-quick reads `[Interface]` (PrivateKey, Address, ListenPort) and `[Peer]` (PublicKey, Endpoint, AllowedIPs, PersistentKeepalive) from `/etc/wireguard/IF.conf` and adds routes for the allowed IPs. |
| `ssh [-p PORT] [-l USER] [USER@]HOST [COMMAND]`, `sshd`, `killall sshd`, `echo USER:PASS \| chpasswd`                                                                                         | ✅     |                                                                                                                                                                                                       |
| `CMD \| CMD`, `grep [-i] [-v] [-c] PATTERN [FILE]`, `tee [-a] FILE`, `cat` from a pipe                                                                                                        | 🟡     | Pipelines take commands that finish at once (not `ping`). grep patterns use JavaScript regular expressions.                                                                                           |
| `CMD ; CMD`, `CMD && CMD`                                                                                                                                                                     | 🟡     | Commands run one after the other; Ctrl+C ends the whole list. Commands have no exit status, so `&&` runs the next one even after an error; no `\|\|`. A `;` inside `{ }` (nft) needs no escaping.     |
| `help [TOPIC\|COMMAND\|all]`, `man COMMAND`, `history`                                                                                                                                        | ✅     | `help` lists topics. There are no manual pages: `man` shows the help line. Commands from other systems (`ifconfig`, `route`, `arp`, `nslookup`…) answer `command not found` plus a `Try:` hint.       |
| `hostname [NAME]`, `clear`                                                                                                                                                                    | ✅     |                                                                                                                                                                                                       |
| Tab completion                                                                                                                                                                                | ✅     | Commands, `ip` objects, help topics, interface names and file names; several matches are listed at once (bash wants a second Tab). No option completion.                                              |
| Loopback                                                                                                                                                                                      | 🟡     | `lo` is interface 1 with `127.0.0.1/8`; the whole `127.0.0.0/8` answers locally and never leaves the device. No `::1`, and `lo` cannot be configured or turned off.                                   |
